# LawSearch · 法律法规检索

一款**完全离线**的中文法律法规阅读器，覆盖 **1,874 部**法规、**69,694 条**条文，
支持中文全文检索、收藏与阅读位置记忆。无需联网即可使用全部功能。

## 特性

### 📚 完整的离线法规库

- **1,874 部**法规、**69,694 条**条文，约 **717 万字**正文，全部随应用打包
- 分类：宪法 8 / 法律 439 / 行政法规 876 / 司法解释 551
- 按「编 / 分编 / 章 / 节 / 条」完整还原层级结构，支持章节折叠
- 首次安装后完全离线，**无任何后台网络请求**

### 🔍 中文全文检索

中文没有空格分词，而 Android 的 SQLite 只提供 `simple` 分词器（按空格切分）。
本项目在入库前把文本预分词成**二元组**（bigram）：

```
「船舶优先权」 → 「船舶 舶优 优先 先权」
```

查询时把整个词的二元组放进同一个短语（要求相邻且有序）：

```
("船舶 舶优 优先 先权")
```

排序不依赖数据库的 rank，而是自行打分：
完整短语命中 > 连续二元组长度 > 覆盖率 > 位置加成。

此外还有：

- **同序容错**：查询词打错导致 0 命中时，自动降级为「各二元组全部出现」，结果标记为模糊匹配
- **单字提示**：单字（「船」「法」）在 bigram 索引里召回率不足 1%，会提示改用二字词

### 🎨 界面

- **液态玻璃**（Liquid Glass）视觉效果：实时背景模糊 + 折射
- 支持自定义壁纸（从设备相册选择）
- 阅读器支持字号调节、章节折叠、深色模式

### ⭐ 其他

- 条文级 / 整部法规级收藏
- 阅读进度记忆（自动记录最后阅读位置）
- 搜索历史
- 时效性判定（有效 / 已修改 / 已被修订 / 已废止）

- **[国家法律法规数据库](https://flk.npc.gov.cn/)**（全国人大常委会办公厅主办）
